# 后续优化：个人时间表达习惯

状态：延期，不进入 2026-08-12 的日报日期修复与 Flash 上线。

## 已确认需求

- 全员通用口径仍是：每天 09:00 前填写日报时，上一自然日是强默认，但不是硬限制。
- Agent2 应结合当前时间、完整原话、近期对话和可信日报事实判断；无法确定时自然追问。
- 个别用户可能有稳定的个人表达习惯。例如庞浩在次日凌晨说“今天”，实际常指刚结束的工作日，而不是日历刚翻到的新一天。
- 这种个人习惯当前没有写入个人记忆，本次也不新增或补写线上记忆。

## 后续设计边界

- 只能记录用户本人明确表达、并经本人确认的时间解释偏好；不得从一次对话擅自推断成长期习惯。
- 个人偏好只作为 Agent2 的上下文提示，不是程序规则，不得绕过模型直接改日期。
- 不得把庞浩或任何个人的偏好复制给其他用户。
- 用户当前消息明确指定日历日期时，当前消息优先；仍有冲突时由 Agent2 追问。
- 记忆必须支持查看、更正和清除，并保留来源与更新时间。
- 实施前需单独测试跨午夜、09:00 边界、跨会话、改口、清除记忆和多人隔离。

## 本次不做

- 不修改现有个人记忆。
- 不新增时间表达记忆字段或工具。
- 不把任何姓名、句式或关键词写进日期判断程序。
