# 未上线能力边界

代码存在不等于生产启用。本文件列出 2026-07-29 受控私有基线中明确不作为生产承诺的能力。

## NOT LIVE

| 能力 | 当前边界 | 启用前要求 |
|---|---|---|
| 数据接入自动发布 | 数据接入和人工确认可用，但解析结果不会自动成为正式来源 | 来源审批、差异预览、回滚和审计闭环 |
| Agent2 对话式新增案件进展 | 现有案件页面/API 与既有进展能力保留；新的对话写入工具不全量开放 | 权限、目标唯一性、版本、回执、真实模型回归 |
| 出差外发通知 | 意图、候选和通知基础设施保留，外发关闭 | 收件范围、幂等、受理/送达区分和回滚演练 |
| 主动案件跟盯发送 | 策略、任务、待回复和发件箱基础设施保留，主动发送关闭 | 触发规则、限频、授权范围、取消和审计验收 |
| 案件进展自动投影到报告 | 投影模型和执行器保留，自动执行关闭 | 事实来源、用户确认、去重、独立修正和回滚 |
| 语义准入强制模式 | 观察、回放和评测代码可保留，不能仅凭模型判断强制写入 | 安全、可用性、数据库和运行门禁全部通过 |
| 离线回放与评测工具 | 只用于隔离验证，不属于在线请求链路 | 输入脱敏、与生产状态隔离、禁止副作用 |
| 沙箱和演示数据 | 只用于本地开发，不得与生产数据混用 | 显式沙箱标识、独立租户、独立凭据 |

## CONTROLLED LIVE

Agent2 工具调用、回执和审计属于受控生产能力：

- 只向经过审批的白名单开放；
- 白名单为空时必须关闭；
- 不能根据聊天上下文猜测目标或权限；
- 不支持的能力应明确拒绝，不能静默回退到写入；
- 任何扩大范围都需要重新验收。

源码仓库不记录白名单数量和标识。

## 不得用作上线依据

以下材料只能证明研发或验证过程，不能单独证明能力已上线：

- 单元测试通过；
- 搜索到生产代码；
- 离线回放得分；
- 沙箱页面可操作；
- 数据库表已经创建；
- 某次历史部署报告；
- 某个 Git 提交存在。

上线裁决必须同时核对发布制品、配置开关、权限范围、数据库迁移、运行入口、只读验收和回滚能力。

## 状态变更

能力从 `NOT LIVE` 变为 `CONTROLLED LIVE` 或 `LIVE` 时，必须在同一个发布变更中更新：

1. 本文件；
2. `docs/PRODUCTION_BASELINE.md`；
3. `docs/CAPABILITY_FILE_MAP.md`；
4. `.env.example` 的安全默认值和说明；
5. 对应测试和内部发布证据。
