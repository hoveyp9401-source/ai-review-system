# 2026-07-29 受控私有生产源码基线

## 定位

本基线由 2026-07-29 实际运行源码整理而来，用于建立可由受控协作者审阅、可继续版本化的生产源码起点。

它不是生产服务器副本，已主动排除：

- 环境配置和凭据；
- 数据库内容、业务文件和搜索索引；
- 完整用户、租户和白名单及其配置；
- 日志、缓存、输出和测试回放；
- 部署包、备份、逐文件指纹和内部审计证据；
- 服务器地址、目录和运行参数。

为保证与生产行为一致，源码中仍可能保留少量必要业务规则常量。本仓库必须保持私有，不能直接镜像或复制到公开仓库。

## 与 GitHub `main` 的关系

在本基线完成源码复核、配置脱敏、测试和合并前，GitHub `main` 不等同于当前生产源码。

只有满足以下条件后，才能把新的 GitHub 发布标记为受控生产基线：

1. 本基线的源码和迁移文件经过双人复核；
2. 所有配置模板只保留空值或安全默认值；
3. 内部证据和业务数据未进入提交；
4. 代表性测试和完整回归通过；
5. 已建立发布标记、回滚包和内部对应关系；
6. 生产部署由该发布制品完成并通过只读验收。

生产环境中的真实文件指纹和配置核验记录继续由内部证据保存，不进入源码仓库。

## 运行组成

| 进程 | 入口 | 责任 |
|---|---|---|
| API | `app.main:app` | 网页、Webhook、业务接口和健康检查 |
| Stream | `python -m app.stream_runner` | 接收钉钉长连接消息并进入统一处理链 |
| Scheduler | `python -m app.scheduler.runner` | 执行提醒、汇总和受控后台任务 |

三个进程共享同一源码基线和配置规则，但应独立启动、独立观察。Scheduler 必须保持单实例，避免重复执行。

## 源码范围

本受控私有基线包含：

- `app/`：生产入口和业务模块；
- `database/`：基础数据库脚本；
- `scripts/`：迁移、回放和核验工具；
- `tests/`：随生产快照保留的安全测试子集；
- `deploy/examples/`：脱敏服务模板；
- `.env.example`、`Dockerfile`、`docker-compose.yml`：安全配置示例。

测试子集不等于完整研发测试库。发布前仍需在受控环境运行完整测试和迁移核验。

## 不变量

- 查询不能产生隐式写入；
- 模型输出不能绕过执行层；
- 跨业务域不能继承写入权限；
- 写入必须绑定用户、目标、版本和幂等标识；
- 外部平台受理不能表述为用户已收到；
- 生产数据、凭据和内部证据不能进入源码 Git 历史。
